# Flappy Mario Game in C++ & OpenGL

A 2D/3D-inspired Mario-themed game developed in **C++ using OpenGL**, created to explore fundamental game development concepts and graphics programming.

The project focuses on implementing game mechanics, player movement, level interaction, rendering, collision handling, and a classic platform-game experience using low-level graphics programming rather than a commercial game engine.

## 🎮 Features

* Mario-inspired gameplay and environment
* Player movement and jumping mechanics
* Collision detection and level interaction
* OpenGL-based rendering
* Game objects and environment elements
* C++ game logic and programming
* Custom graphics programming without a game engine

## 🛠️ Technologies

* **C++**
* **OpenGL**
* **Computer Graphics**
* **Game Development**

## 🎯 Project Purpose

This project was developed as a practical exploration of **C++ game programming and OpenGL graphics development**, with a focus on understanding how core game systems such as rendering, movement, interaction, and collisions can be implemented at a lower level.

## 🚀 Learning Outcomes

Through this project, I gained practical experience with:

* OpenGL rendering and graphics programming
* C++ game development
* Implementing basic gameplay mechanics
* Handling player movement and collisions
* Structuring a game without relying on a commercial game engine
* Understanding the fundamentals of real-time interactive graphics
